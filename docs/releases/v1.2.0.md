# v1.2.0 — Traced light on the Tabletop

The Tabletop now traces light in 3D from laser sources through Component surfaces. Mirrors and Beam cubes can aim at another Component; the Tabletop turns them as the Setup moves. Dropping an unaimed Mirror into light can catch a target, and **F** flips its fold.

Saved Beams still record the intended path and each branch's appearance. If an older Setup's path differs from the trace, that drawn path stays on the table for editing. The status bar lists trace checks, offers Colours and Power views, and lets you return to the earlier drawn-Beam view.

This release also adds laser light colours, a Light panel for traced routes, and a one-time guide to the new Tabletop behavior. Setup files remain compatible with earlier versions.
