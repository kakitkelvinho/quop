Polarization in a 3D trace — throwaway prototype

Question: Can a Beam carry power and a transverse complex field through a 3D mirror turn, then let HWP, PBS, Polarizer and Faraday rules determine outgoing power and polarization?

The field is stored as a normalized complex 3-vector perpendicular to travel: the same information as a Jones vector plus a carried basis. Each button represents one surface hit. The model uses the engine's surface-rule shape, but this standalone file does not import traceScene or search for physical hits. It tests the state passed between hits. Free-play actions apply to every live branch. Power is a fraction of one Laser source. No interference or coating calculation.

What to look for

First try “HWP + PBS”: power moves between ports but totals 100%. “Polarizer loss” leaves 50% in light and records 50% absorbed. “Mirror phase” changes linear light to circular while power stays 100%. “Faraday return” gives two rotations in the same lab direction.
